## 💻 Cara Menjalankan Website Secara Lokal

### Cara 1: Langsung Buka di Browser (Paling Praktis)
Cukup **klik dua kali (double click)** file `index.html` pada file explorer Anda.

### Cara 2: Menjalankan Server Lokal (Python)
```bash
python -m http.server 3000
```
Lalu akses browser di: [http://localhost:3000](http://localhost:3000)
